PROYECTO 0.1
Las funciones del proyecto 0 estan en el archivo funciones.
Las funciones para trabajar con .json esta en funcionesjson.
En analisis_smn se carga y lee el json.

Comandos usados:
Para cargar y leer .txt
python analisis_smn.py datos/observaciones_smn.txt
Para leer .json
python analisis_smn.py obs_json/observaciones_smn.json

PROYECTO0
Este proyecto usa datos de la pagina:
https://www.smn.gob.ar/descarga-de-datos.
La carpeta que se obtiene al descargar los datos debe descomprimirse
y el .txt que esta dentro debe guardarse en una carpeta llamada 'datos' 
y con el nombre observaciones_smn.txt. 
En la misma carpeta donde se encuentra la carpeta datos se guardan las 
funciones que usaremos para trabajar con estos datos que deben 
ejecutarse con el comando:
python analisis_smn.py datos/observaciones_smn.txt.
